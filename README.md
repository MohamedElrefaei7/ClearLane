# ClearLane

ClearLane is an interactive map of New York City's bike network showing, for any day of the week and hour of the day, how likely each part of the network is to be **reported** as blocked (double parking, standing vehicles, etc.). Everything shown is *reported* obstruction derived from NYC 311 "Blocked Bike Lane" service requests, not observed obstruction — complaint volume depends on who rides and who reports, and varies by neighborhood.
